# Tomography 中文 README 设计说明

## 目标

新增 `src/qtools/tomo/tomography/README_CN.md`，面向需要使用和二次开发本仓库量子态层析代码的中文读者。文档应以当前 `qtools` 包的实际接口和示例文件为准，并明确区分已实现能力与未来的 OAM 无限维扩展。

## 内容范围

1. 说明 `Tomography` 类从初始化、导入 TOML/JSON、运行 `run_tomography()` 到读取输出和计算态性质的完整流程。
2. 解释 JSON 数据结构：测量态、basis、counts、探测器、积分时间、相对强度、偶然符合、串扰和探测器效率。
3. 解释 TOML 配置项及其与内部 `conf` 键的对应关系，提醒旧版 `.txt` 格式仅作兼容。
4. 描述代码分层：导入和预处理、测量算符构造、线性反演、MLE/HMLE、显示与高层 interface。
5. 单独设置“MLE 代码实现详解”章节，覆盖：
   - 从测量计数到 POVM/投影算符的构造；
   - Cholesky-like `T` 参数化如何保证半正定密度矩阵；
   - `maxlike_fitness` 的预测计数和加权残差；
   - `leastsq` 的初值、优化参数、输出和归一化；
   - 2 个探测器、偶然符合、串扰、效率和漂移校正如何进入模型；
   - 线性反演初值、HMLE beta 规则、拟合残差的解释和常见失败原因。
6. 给出从有限维 qubit 扩展到 OAM 的工程路线：截断维度、模式基测量、POVM/模式串扰、稀疏或低秩先验、矩阵规模与实验标定，并说明真正无限维只能通过截断或参数化模型近似。

## 写作约束

- 示例路径使用仓库当前路径 `src/qtools/tomo/ExampleFiles/`，同时提供从仓库根目录运行的代码片段。
- 公式只解释代码真正实现的模型；不把注释中未实现的 BME 宣传为可用方法。
- 对当前代码中存在的旧接口、内部键名大小写兼容和潜在限制做简短提示，但不在本次任务中修改算法。
- README 不修改 LICENSE 内容，也不把 LICENSE 中的法律文本当作技术说明。

## 验证

- 检查文档中公开方法和字段名与源码一致。
- 使用当前 1-qubit JSON 示例运行一次 `Tomography` 流程，确认文档代码的导入和返回值结构正确。
- 检查工作区 diff，避免改动与本次文档无关的已有用户修改。
