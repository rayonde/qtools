######################################################################
## 
## Time Controller Software Application Release 1.11.0 - 13.07.2023
##
##                  Release Notes
##
######################################################################


New features:

    * SYS - [ID1000] Support of the new HW boards version B1
    * SYS - [ID1000] Support of input shaper (only on HW boards version B1 and above)
    * SCPI - Deadtime configuration example
    * GUI - Input shaper feature (only shown when available)


Bugs correction:

    * SYS - Start index are sometime wrong
    * ESW - [ID1000] Improve high-resolution error resiliency
    * SCPI - STAR:SELE? command returns a wrong answer
    * SCPI - HIST#:REF:FILT and HIST#:STOP:FILT? commands return wrong answers
    * GUI - Time Controller GUI doesn't save histogram when acquisition is manually stopped
    * GUI - Time Controller GUI crash when histogram bin count is changed through SCPI commands during an acquisition
    * GUI - Time Controller Configuration Editor crash with bad IP address format 


Known bugs and limitations:

    * SYS - [ID900] Erroneous lower frequency is displayed on counters if the count rate is higher than the maximum supported value (1 Gcps in HS mode, 25 Mcps in HR mode)
    * SYS - [ID1000] Erroneous lower frequency is displayed on counters if the count rate is higher than the maximum supported value (1 Gcps per channel in HS mode, 300 Mcps total over all channels in HR mode)
    * SYS - Sometimes, the Time Controller does not restart automatically after the update
    * SYS - Timestamps file might be missing when saved in text format
    * ESW - [ID1000] In high-resolution mode, bad threshold might leads to timestamp loss (might require power-cycle)
    * ESW - [ID1000] High-resolution error auto-correction leads to timestamp loss on all channels
    * GUI - Counter trace points at maximum value may not be visible
