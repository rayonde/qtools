# 双光子偏振基底与 HWP 扫描设计

## 目标

完善双光子偏振纠缠表征界面，使状态基底、Alice 多选分析、Bob 半波片角度和绘图含义与物理约定一致。删除没有实际用途的演示入口，并保持后端数据流单一、直接，不增加旧接口兼容层或别名。

## 状态与基底

前端提供两种状态编辑基底：线偏振 `H/V` 和圆偏振 `R/L`。圆偏振定义固定为：

`|R⟩ = (|H⟩ + i|V⟩)/√2`

`|L⟩ = (|H⟩ − i|V⟩)/√2`

页面在圆偏振选择器附近显示该定义。用户输入的四个复振幅始终是所选基底下的系数；后端收到 `state_basis` 和 `amplitudes` 后，将所选基底下的双光子系数转换为内部 H/V 表示，再完成所有测量计算。切换显示基底时，当前物理态转换到新基底后再填充输入控件，因此不会改变物理态。

四个输入幅值使用整体 L2 归一化。每次滑块输入后前端立即归一化四个幅值并刷新显示；后端再次归一化作为计算边界，避免非法或漂移输入影响结果。

预设只保留四个 Bell 态：`Φ+`、`Φ−`、`Ψ+`、`Ψ−`。预设根据当前编辑基底生成对应复振幅，点击后立即刷新状态和图表。删除“相位演示态”和“随机纯态”。

## Alice 主图

Alice 的 `H/V/D/A` 改为多选按钮，默认只选 `H`。删除“同时显示正交结果”选项。每个选中的 Alice 基底对应一条主曲线，曲线值为 Bob 正向输出的条件符合率 `P(Bob+ | Alice)`；不再为 Bob 负向输出额外绘制虚线曲线，因此一组 Alice 选择不会产生重复曲线。

主图图例放在图上方。颜色固定为高对比方案：H 蓝色、V 红色、D 绿色、A 黄色。主图默认使用归一化符合率，仍保留概率/符合率切换控件供比较。D/A 相位扫描作为辅助图保留，随当前内部 H/V 物理态计算，不再作为 Alice 主图的替代视图。

## Bob HWP 扫描

Alice 的线偏振角统一记为 `a`，Alice HWP 机械角记为 `theta_a`，两者满足 `a = 2 * theta_a`。Bob 的线偏振角统一记为 `b`，Bob HWP 机械角记为 `theta_b`，两者满足 `b = 2 * theta_b`。因此 Bob HWP 转动 `0°/22.5°/45°` 时，Bob 的正向分析方向分别为 H/D/V。扫描请求只使用 `theta_b` 范围，不保留旧的角度别名。

主图横轴主坐标标为 `HWP rotation theta_b`，顶部辅助坐标标为 Bob 偏振角 `b`，关键 HWP 刻度标记 `-45°、-22.5°、0°、22.5°、45°`，并在对应位置标识 V/A/H/D/V 分析方向。CHSH 图横轴使用相对于 Alice 的 `b - a`。CHSH 的 `a`、`a′` 和 `b` 均使用连续角度；常用的 `0°、22.5°、45°、67.5°、90°` 通过滑块刻度提示，理论 Smax 不依赖扫描步长。关键分析表同样同时显示 `b` 和 `theta_b`。扫描数据只返回每个 Alice 选择的一条正向曲线；互补输出由概率守恒体现，不单独画线。

## API 与数据流

`POST /api/calculate` 的请求字段为：

- `state_basis`: `linear` 或 `circular`
- `amplitudes`: 当前编辑基底下 HH/HV/VH/VV 或 RR/RL 等四项的 magnitude/phase
- `alice_bases`: 选中的 Alice 基底数组
- `phase_target`: 要扫描相位的当前振幅标签
- `scan`: `{min, max, step}`，表示 HWP 机械角范围

后端只实现这一套新字段，不接受或生成 `alice`、`show_both`、旧角度别名等兼容字段。返回值包含：H/V 内部归一化态、当前基底下的显示态、每个 Alice 基底的一条 `conditional`/`joint` 曲线、HWP 关键测量、相位扫描和纠缠度。

## 验证

测试覆盖：

1. 四个 Bell 预设的复振幅和纠缠度。
2. 线偏振与圆偏振表示转换后测量概率一致。
3. 幅值输入自动归一化，零态被拒绝。
4. 多选 Alice 返回的曲线数量等于选中基底数量，且无虚线/负输出重复曲线。
5. 默认绘图模式为条件符合率。
6. HWP 角 `0°/22.5°/45°` 对应分析方向 `H/D/V`。
7. Φ+ 在 D 基底对应正确的确定性相关结果。
